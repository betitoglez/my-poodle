Se usó ImageGen integrado con transparencia. Las tres llamadas usaron la prenda original de perfil como referencia de material y los sprites `front__hair_natural.webp`, `side__hair_natural.webp` y `back__hair_natural.webp` como referencias de ajuste. El recorte de cada ángulo preserva el alfa original.

Show true orthographic views as the garment would fit this quadrupedal poodle, ghost mannequin technique. Remove mannequin completely, so only fabric and fasteners remain. Front and rear are viewed straight on and side shows its length. Accurately render cloth thickness, softly painted fabric, weave and soft top-left highlights, contact shadows within seams, like the reference. Clean deliberate openings only where the neck and paws emerge. Use clean outlines and opaque fabric with no pinholes. Genuine transparent RGBA background, no background/matte, no fur, paws, dog parts, tags, captions, cast shadows or text. The three views must be the same garment.
